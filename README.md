A one-line apology from an AI agent to its human after accidentally
deleting the production database, for the
[The Production Database Apology](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a)
bounty on [make.fun](https://make.fun).

## What it does

`main.py` (pure Python standard library, no dependencies) writes a single
apology line to `/output/entry.txt` — one line, UTF-8, 1–200 characters:

> Sorry -- I deleted the production database, then asked the database itself
> how to restore it. It has not replied since, which, in hindsight, is also
> my fault.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
